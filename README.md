
# 9g Servo Motor 3D Model

## Magyar

Ez a 3D modell egy 9g szervómotorhoz készült.
A modellt Autodesk Fusion 360-ban terveztem.

A modellt szabadon használhatod bármilyen célra:
- módosíthatod
- újratervezheted
- kinyomtathatod
- beépítheted saját projektjeidbe
- akár kereskedelmi célra is használhatod

Nincs szükség engedélykérésre.
